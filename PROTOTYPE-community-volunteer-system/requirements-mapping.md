# Requirements Mapping

All requirements below are **candidate requirements** drawn from the coursework brief. None are confirmed by stakeholders.

| Screen | File | Purpose | Related requirement (candidate) | Unresolved questions |
|---|---|---|---|---|
| 1. Browse Events | `index.html` | Let volunteers discover events | Volunteers need to view event information and find suitable events | Is search or category filtering required? Which categories are correct? |
| 2. Event Details | `event-details.html` | Review an event before registering | Volunteers need clear event and task information before deciding | What are the eligibility rules, deadline, capacity, and approval policy? Which skills or items are actually needed? |
| 3. Registration Form | `register.html` | Provide a simple registration form | Volunteers need a simple way to register | Which fields are required? Is availability collected here? What is the privacy notice? |
| 4. Incomplete Registration | `registration-error.html` | Illustrate an incomplete-form state | Volunteers need clear feedback when information is missing | Must these fields be completed before submission? How should errors be shown? |
| 5. Registration Submitted | `registration-submitted.html` | Acknowledge a submission | Volunteers need clear feedback about what happens after submitting | Does registration require approval? How and when is participation confirmed? Are notifications sent? |

## Unsupported assumptions deliberately avoided
- No claim that a registration is approved or participation confirmed.
- No eligibility rules, deadlines, capacity limits, or approval policies.
- No claim that search, filters, or form submission work.

## Out of scope for these five screens
Organiser, coordinator, supervisor, and IT Support functions (event creation, volunteer assignment, attendance, account management, security) are not shown in this volunteer journey.
