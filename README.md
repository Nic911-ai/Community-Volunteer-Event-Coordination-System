# Community Volunteer & Event Coordination System (Prototype)

A five-screen, low-fidelity HTML/CSS prototype for a Requirements Engineering coursework (Week 7). It shows one user journey: **a volunteer finds a community event and registers.**

## Technologies
- HTML5 and CSS3 only. No JavaScript, frameworks, backend, database, or login.

## How to open and test
1. Unzip the folder.
2. Double-click `index.html` (or right-click, then Open with, then your browser).
3. Follow the journey: Browse Events, Event Details, Register, then Submit.
4. Optionally open `registration-error.html` through the link on the registration page.

## Important limitations
- All events are **fictional samples**.
- The search box and category filters are visual only.
- The registration form stores and sends **nothing**. "Submit Registration" simply opens the next page.
- The prototype never says a registration is approved; approval rules are an open question.
