Initial Discovery 
1. Facts
- Some of the community events require multiple volunteers to coordinate a activities.
- volunteers may have different roles, responsibilities and availability.
- Event organisers need to know which volunteers are available for some specific events.
- Volunteers need to know the information about the events, venue, task, time, task and reponsibilities
- Change of event must immediately notified to the volunteers that they sign up to.
- Volunteers may choose in volunteering in multiple events.
- Event organiser need to monitor the volunteer roles.
- The system must ensure is easy to use as we expect some volunteers may experience technical diffuculties.
- Volunteers may access the system by using phones, tablets or computers.
2. Assumptions
- Volunteer will be needing to create an account.
- Event organisers will be responsible for creating and managing events.
- Volunteers should be able to choose the events or task they are interested in.
- Organisation will have someone responsible for managing the system.
- The system will be used for community events rather than commercial events.
3. Unknowns
- How many volunteers might use the system at the same time?
- What types of community events will be supported?
- Should volunteers be able to cancel?
- What happens if the volunteers did not show up?
- Can volunteers be able to communicate to each other through the system?
- Should organisers be able to assign specific tasks to individual volunteers?
- Should volunteers be able to swtich task?
- Volunteers and organisers should have an emergency contact information be display
- What personal information can be store?
- Are there different levels of administrator access?
- Should volunteers be able to record their hours?
- Are report required?
- What happens if an event is cancelled?

- Event Organisers/ Create events and coordinate volunteers, Managers	Manage volunteers and oversee events,manage volunteers during events
System Administrator	Manage users, permissions, and system configuration

- Find suitable volunteer opportunities.
- View upcoming events.
- See event details.
- Indicate availability.
- Sign up for events.
- Understand assigned responsibilities.
- Receive notifications about changes.
- Cancel or update participation when necessary.
- Organiser goals
- Create and manage events.
- Define the volunteers and roles required.
- View volunteer availability.
- Assign volunteers to tasks.
- Identify unfilled positions.
- Communicate changes.
- Monitor volunteer participation.
- Manage event information.
- Organisation goals
- Maintain an organised volunteer database.
- Reduce manual coordination.
- Improve communication.
- Reduce volunteer scheduling conflicts.
- Make event planning more efficient.

- Volunteer profiles.

- Event registration.

- Event pasticipant lists.
- Notification.
- Event updates and cancellation.
- Volunteer management.
- Event management.
- Role-based access.
7. Candidate Requirements
- Volunteers
- The system shall allow volunteers to create account.
- The system shall allow volunteers to log in and manage their profile.
- The system shall allow volunteers to browse and register available events.
- The system shall allow volunteers to provide their availability.
- The system shall notify volunteers any changes for the events.
- The system shall allow volunteers to withdraw from an event 2 weeks before the event.
- Organisers
- The system shall allow organisers to create community events.
- The system shall allow organisers to cancel event.
- The system shall allow organisers to create and specify time, date, location, description, and how many volunteers neede and role required for an event.
