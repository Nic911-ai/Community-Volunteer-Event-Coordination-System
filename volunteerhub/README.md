# VolunteerHub - Make Every Hour Count
Open `index.html` in a browser (double-click). No install, API key or server needed. Internet only for the Google Font (falls back safely).
Files: one HTML shell per page, `css/style.css`, `js/app.js` (data, localStorage helper `S`, and one view function per page in `V`).
Status flow (demo): Submitted -> Pending Review -> Approved/Rejected -> Completed; Cancelled from any active state. Buttons labelled "Demo" simulate an organiser.
localStorage is demo-only: not secure login, no cross-device sync. All events/stats/organisers are fictional. Use Profile > Reset demo data to start over.
Quick test: Explore > search/filter/sort > Sign Up > submit (duplicate blocked) > My Registrations > advance statuses > Profile badges > Notifications > refresh page.
